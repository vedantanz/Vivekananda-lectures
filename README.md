# Vedanta Lectures of Swami Vivekananda

Study guides published by the Ramakrishna Vedanta Centre NZ for the Ritam course *Study of Vivekananda Lectures* (vedanta.nz).

Each guide lives in `guides/NN-slug/` with a mobile web page (`index.html`) and a printable PDF. Lecture texts are from *The Complete Works of Swami Vivekananda*; headings, summaries, glossary, Bridge to Wellbeing and questions are editorial additions by the Centre.
